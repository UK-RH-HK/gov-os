# Framework Change Proposals

Accepted framework lessons become change proposals here (`FCP-xxxx.yaml`, record type `decision` with
`tags: [framework-change-proposal]`). A proposal is implemented only in this canonical repository, tested against the
synthetic fixtures, independently reviewed, and released; consumer projects receive it through `gov update`.
Product-owner amendments recorded directly as decisions (e.g. D-0002) reference the chat message that authorised them.
