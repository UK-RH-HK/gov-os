# W2-153 The role template delivered at launch (W2-128's code half, part 2)

**Why.** R3-1 to R3-3: role files never reached launched sessions. W2-128 (`DAEO-t8mp`) wrote the templates; the CTO
split its code half into W2-152 (`gov brief`) and this ticket (a delegated P2 under DEC-1112 (3);
`packages/LIFT-1/D5-STATUS.md`). W2-128's S9 is built here; W2-128 closes after both.

**Interface (D5 row 9, stated before the pair starts).**
- **The role → template map** (one constant in `launcher.py`, reused by the portability check): engineer
  `role-engineer`, independent-test-designer `role-test-designer`, independent-auditor `role-reviewer`, product-spec
  `role-product-spec`, research `role-research`, lead and orchestrator `role-lead`.
- **The flag** is appended to the CLI arguments the launcher builds (after the caller's), as
  `--append-system-prompt-file <absolute path>`; `<root>` is the launch's repository root (the worker's worktree).
- **The skills lists:** engineer `[test-driven-development]`, independent-test-designer `[test-design]`,
  independent-auditor `[audit]`, product-spec `[change]`, research `[discovery]`, orchestrator `[orchestration]`; the
  test designer's `test-design` only once W2-128 has reconciled that skill with DEC-963 (review F7): until then it is
  left out and the case says so.
- **The copies** are written only by the ACT (DEC-315): this ticket commits no `.claude/` file.

- **Decided after the build (2026-11-10, the CTO, DEC-1112 (3)):**
  - The source's skills list sits under `claudecode: skills:`, because rulesync 24.0.0 passes `skills` to the
    generated agent only there. A top-level `skills:` is dropped, so the agents would preload nothing.
  - The existing launcher unit tests whose fixtures start a session (`test_runs.py`, `test_w1_28.py`, `test_w1_32.py`,
    `test_w2_136_plan_check.py`) write the role's `.claude/templates/<stem>.md` in their fixture. W2-136's case that
    the caller's arguments end the argv now allows the one appended flag. Paths added. Refusing only when the folder
    exists was not taken: it would fail open against F1.
