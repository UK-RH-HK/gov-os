# The cases of this project that cannot hold under parallel load (DEC-372, DEC-527).
#
# `gov close` runs the ticket's acceptance tests and the regression tests in parallel, and the cases
# this list names afterwards, alone and serially, each exactly once. A case no line names runs in
# parallel. The list is read by `gov close` and by nothing else; it changes nothing of what a case
# asserts. Its rules are in tests/acceptance/W1-30/README.md, "Round 11".
#
# One entry on a line: the beginning of a pytest node id, relative to the project (a test file, or
# `file::function`, which names every parameter set of the function). What follows ` #` is a comment.
# In this project every entry says which of the four kinds it is:
#   latency               asserts a time bound
#   real-model-or-daemon  starts or asks a real model or a real daemon
#   live-session          launches a real session
#   race                  races its own processes by design
# A case is not listed merely because it is slow.
