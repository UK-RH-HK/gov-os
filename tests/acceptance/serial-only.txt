# The cases of this project that cannot hold under parallel load, and where each one runs (DEC-372, DEC-527;
# reworked by W2-57 as P-IS-6's first table, DEC-889 item 5).
#
# The form. One entry on a line: the beginning of a pytest node id, relative to the project (a test file, or
# `file::function`, which names every parameter set of the function). What follows ` #` is a comment, and a line
# that begins with `#` is a comment. Every reader takes the entry as the text before ` #`: `gov close`'s plugin,
# the orchestrator's nightly script and W1-30's r11 alike. In this project the comment of every entry is
#
#     <route>: <kind>: <reason>
#
# and the reason is said in words. Its rules are in tests/acceptance/W1-30/README.md, "Round 11", and W2-57's README.
#
# The routes. The first word of the comment tells a reader where the entry runs:
#   serial    kept in the close: left out of its parallel phase and run afterwards, alone and serially, each
#             exactly once, as before
#   nightly   routed to the nightly: collected by the close and left out of both its phases (deselected from the
#             parallel phase, never ignored and never skipped, and not run in the serial phase)
# Every entry of either route runs in the nightly, alone, after the nightly's parallel run less this list.
#
# The kinds, and the route each takes (DEC-889 item 5):
#   latency       asserts a time bound: serial, alone in the close's quiet serial phase
#   daemon        starts or asks the codebase-memory daemon: serial in this run (W1-16's cases that start no
#                 daemon are not listed; they run in the parallel phase)
#   race          races its own processes by design: serial in this run (W1-09's two move to the parallel phase
#                 after one green nightly there)
#   real-model    starts or asks a real model (the embedder, the reranker): nightly
#   live-session  launches a real session (`gov launch`, the Claude CLI): nightly
#
# A case is never listed merely because it is slow. A case no entry names runs in the parallel phase, whatever its
# name says and whatever markers it carries: a marker routes nothing.
