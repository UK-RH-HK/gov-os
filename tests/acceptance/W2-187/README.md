## How the tests reach the code

- **The command line, as the callers run it:** `python3 -m gov.memaudit <subcommand> --sets-root <root> ...` and
  `bash governance/project/orchestration/tools/memaudit_cron.sh --repo <dir>`, each in a child process, judged by exit code,
  printed lines and the files under `<runs>/indep/memaudit/<key>/`, `<sets root>/runs/<set>/<week>/` and the key folder's
  `indep/`. Every child gets this tree's `src/` first on `PYTHONPATH` (a session fixture fails the run otherwise). The new modules
  (`gov.memaudit.standing`, `maintain`) are never imported; `declare.bar` and `declare.ROUNDING` are read in a child.
- **Only the seams the Interface names:** the flags of I1 and the environment `GOV_INDEP_RUNS_DIR`, `GOV_MEMAUDIT_NOW`,
  `GOV_MEMAUDIT_MAINTAIN_TIMEOUT_S`, `GOV_MEMAUDIT_GATE_POLL_S`, `GOV_MEMAUDIT_GATE_MAX_S`, `GOV_MEMAUDIT_PYTHON`,
  `GOV_MEMAUDIT_SETS_ROOT`, `GOV_MEMAUDIT_GATE`.
- **Planted under pytest's `tmp_path`:** the sets root, the runs folder, a repository with its branch, a store link (a git worktree
  at the audit commit with a planted `.gov-runtime/store.db`), a planted `gov` (`fake_gov_x.py`: W2-171's `retrieve` plus
  `result.store.commit`, `rebuild`, `links`), W2-171's fake `claude`, W2-172's launch stub, gate stub, crontab and file-access spy,
  an interpreter shim for the wrapper (`py_shim187.py`), a function spy (`fn_spy.py`). Never the real sets root, runs folder,
  HOME, crontab, a model or a GPU; no hidden half or memory-verdict folder is opened.
- **The standing set** `memory-standing-20261101`: 80 questions, `q80` the nonexistent-id question (counted in n, scored apart),
  `q01-q79` each citing a heading of `docs/std/s<NN>.md`. Its entry in the sets root's path map is planted (the Interface does
  not say who writes it before the pre-flight loads it: see `unresolved`). The oracle (`StdScenario`, `StdExpected`) is checked
  against the existing fresh path (`measure` and `judge` on the same 80, planted ranks and verdicts: right, wrong, hit@5, A1/A2,
  McNemar, misses by outcome and rank all agreed).
- **Revised earlier files (DEC-1156 (7)):** the bar values in W2-170's and W2-171's helpers and the cases named in the ticket
  (`Rewrite-Reason: DEC-1179 (2)`); W2-172's two helpers point `mem` and `audits_log` at the key folder (`DEC-1179 (5)`).
- **Cost:** 9 whole standing runs and 7 whole fresh audits are made once per session (about 15 s each) and only read, and three small worlds run the fault rule's cases; the week
  rule's table uses planted week folders and a busy gate (`GOV_MEMAUDIT_GATE_MAX_S=0`), which stops a run before any search.
- **Split (DEC-1179 O8 (a)):** S10 is `test_w2_187_s10_maintain.py` with `w2_187_maintain.py`; S11 is `test_w2_187_s11_cron.py` with
  `py_shim187.py` and `call_walls_act.py`: they move to W2-187b whole.
- Run: `python3 -m pytest tests/acceptance/W2-187 -q -m "not local_only" -k "not real and not green_here and not time_limit"`.
