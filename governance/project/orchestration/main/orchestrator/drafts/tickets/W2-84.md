# W2-84 The guard refuses an evaluation set's hidden part under every tree of the repository: the main tree, every worktree and the run clones

Card: `docs/plan/WAVE_2_WBS.md` §2 (W2-84), from the owner's answer of 2026-10-29 to P-W2-H063-1, option (a) (DEC-950 item 1), on memory's critical path.

- **Why:** the guard's refusal of an evaluation set's hidden part (DEC-820 (d)) is rooted at the session's own project root. `gov.guard.reads.parts` builds the hidden part as one `_Part` on `os.path.realpath(root)`. The orchestrator's probe (`tools/probe_hidden_rooting.py`, `policy_refusal` on 2026-10-29) found, for a measured engineer:
  - its own tree's hidden file: refused;
  - the main tree's copy, another worktree's copy and a run clone's copy under `~/gov-os-runs/`: allowed.

  Once W2-61h's questions merge into `w2/integrate`, every measured session in any worktree could read them by an absolute path, and W2-61's measure would lose its hidden half (row W2-H063). The worktrees also share one object store, so a commit that holds the hidden part can be shown from any tree.
- **What exists:**
  - `_hidden` already gives the globs of the sets that measure the session, by role or by ticket, and fails closed on a malformed set.
  - `_Part.inside` matches a path under its one root. `_Part.files` walks only that root's folders, within `_MOST_FILES`; `os.walk` passes over a folder it cannot read without a word.
  - `_Judge.spellings` already judges every path as written and as its real path.
  - `_git` runs git with a 5-second timeout and fails closed.
  - `gov.guard.runs.root()` names the runs root in the session's home. An own folder there carries the `.gov-os-repository` marker naming the common git directory (DEC-751).
  - The new code reuses all of these and copies none of them.
- **Order of work:**
  1. The lead's design note, in its scratch: how the trees are listed, how the run clones are matched, the git routes, the fail-closed cases, and the cost per call.
  2. Tests first, checked red.
  3. The tree lister and the hidden part over every tree, in `src/gov/guard/reads.py` only (`parts`, `_hidden`, `_Part`, and the judge's git route where the design needs it).
  4. The CIT-E.
  5. The review (FULL).
- **Place:**
  - Priority 3 of the owner's standing priorities (DEC-946, memory), ahead of W2-61h (`DAEO-h2k3`). It starts as soon as the gate allows. W2-61h's auditor starts only once this ticket is merged and pinned, and W2-61's hidden half is scored after that.
  - **W2-05** holds `src/gov/**/*.py` for the git environment of git calls, and its sweep may later touch `reads.py`'s `_git`. That is a line overlap, not a file split. This ticket changes no git call's environment. Whichever of the two merges second merges back.
  - **W2-67** holds `tests/unit/guard/**` as a glob. This ticket writes only new `test_w2_84*` files there and edits no existing file.
  - The path map is the orchestrator's; this ticket does not change it. The launcher's `check_sets` (W2-60a and W2-56 hold `src/gov/launch/**`) stays as it is.
- **The test designer's files:** `tests/acceptance/W2-84/`. Everything is planted in temporary folders under a temporary `HOME`:
  - a repository with its own path map and a planted evaluation set that measures the engineer;
  - the main tree, two worktrees and a run clone under the temporary `~/gov-os-runs/`, each holding the hidden part;
  - a symbolic link into another tree's hidden folder;
  - a tree that cannot be listed (fail closed);
  - a revision that holds the hidden part while the session's own tree does not.

  Nothing reads or plants anything in this repository's `fixtures/evaluation/**/hidden/**` or the real `~/gov-os-runs/`.
