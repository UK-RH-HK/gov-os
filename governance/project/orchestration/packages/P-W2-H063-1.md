## 2. What happened
- **Found** by a brief-drafting helper on 2026-10-29, and checked by the orchestrator with the guard's own `policy_refusal` (`tools/probe_hidden_rooting.py`).
- **The cause:** `gov.guard.reads.parts()` roots the refusal at the session's own project root. For a measured engineer the probe found:
  - its own tree's hidden file: **refused**;
  - the main tree's copy: **allowed**;
  - another worktree's copy (W2-61h's): **allowed**;
  - a run clone's copy under `~/gov-os-runs/`: **allowed**.
- **Recorded** as row W2-H063 (`0417951b`). W2-61h is held, so no hidden file exists yet and nothing has leaked.

## 3. Why it matters
- **Merging W2-61h exposes the answers.** Once its questions merge into `w2/integrate`, every measured session in any worktree can read them by an absolute path, so the measure loses its hidden half.
- **The cost of no hidden half:**
  - without one, W2-61's figures are measured only on questions the retrieval tickets can see;
  - the copy's entry criterion would then rest on a self-tuned measure;
  - and the memory chain (W2-03, W2-55, W2-64, W2-04, …) repeats that measure after each ticket.

  - The change: W2-84, engineer, FULL (a guard fault fails open).
