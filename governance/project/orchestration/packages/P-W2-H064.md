# P-W2-H064: `gov check`'s path-map check reports green without checking anything (P1, fails open)

For the owner. Under the Wave 2 finish line (prompt §13), a fail-open found in ordinary work comes to you as a package before any round.

## 1. Context
`gov check` runs a check called core-pathmap. It is meant to confirm that every tracked file in a repository belongs to exactly one namespace of the path map (`governance/project/path-map.yaml`). The namespaces decide what memory indexes, how test selection scopes a change, and how the guard reads paths. The check's code is `src/gov/check/pathmap.py`; it has not changed since W1-26 (`935d9c99`). W2-78's lead found the fault on 2026-10-30. W2-78 is parked (DEC-954 Q5), so the finding was filed as Wave 2 list row W2-H064.

## 2. What happened (checked in the code, 2026-10-30 22:20 GMT)
- `pathmap.py:47-49`: if `namespaces` is not a list, the check returns no findings. This repository's path map writes `namespaces` as a mapping, which is the form its schema states. So on this repository the check judges nothing and reports green.
- `pathmap.py:40-45`: a path map that cannot be read or parsed also returns no findings, so it reports green too.
- The effect: "every tracked path is in exactly one namespace" has never been checked here, and would not be checked in an adopted repository either (EXAMIN's copy included).

## 3. Why it matters
The namespaces drive memory's indexing (W2-86, W2-91), scoped test selection (DEC-953 item 4) and adoption (W2-88). A file in no namespace, or in two, silently falls out of memory or out of a test selection, and the check that should say so is green. Classification: **ordinary work: yes**, because every `gov check` here runs it. **Consequence: fails open.**

## 4. Options
- **(a) A small ticket of its own (W2-95, STANDARD, about 60 lines, about 4 to 6 hours with its tests). Recommended.**
  - The check reads the mapping form the schema states, judges each tracked path against exactly one namespace, and names each path in none or in two. A path map that cannot be read is a finding, never green. Planted cases for both forms.
  - Paths: `src/gov/check/pathmap.py` and its unit tests. These overlap no running ticket (W2-64 holds `src/gov/check/schema.py`; W2-16, W2-20 and W2-37 hold `commands.py`).
  - It can start as soon as the gate allows.
  - Risk: once fixed, `gov check` may go red on real overlaps in this repository's path map. Those are then fixed in the path map's own block, or listed. Under DEC-953, `gov check` does not gate closes, so a red holds no close.
- **(b) Fold it into W2-88 (memory for any repository), as the draft proposed.** It adds `src/gov/check/pathmap.py` to W2-88's paths at no extra ticket. But W2-88 is FULL, about 500 lines, and waits on W2-81 and W2-76. The fail-open stays for days to weeks, through memory's measures that depend on the namespaces.
- **(c) Defer it to Wave 3.** This costs nothing now, but EXAMIN's copy would then be adopted with a path-map check that checks nothing, which goes against K9's entry criteria (Wave 2-grade evidence for every capability the copy relies on, DEC-941 item 7).

None of these changes the Contract or a standing decision. Option (a) adds one ticket to Wave 2's minimum (scope growth, named in the weekly numbers).

## 5. Recommendation
**(a), confidence high.** It is small, it touches no running ticket's files, and it removes a fail-open on memory's critical path before W2-86, W2-91 and W2-88 rely on the namespaces.

## 6. What it blocks, and what waiting costs
It blocks nothing running. Until it is fixed, a path in no namespace or in two goes unreported, and memory's measures (W2-61's, then the 48-question set) may count misses whose cause is a namespace gap. Waiting a day costs nothing measurable; waiting until W2-88 costs the evidence that W2-86 and W2-91 rely on.
