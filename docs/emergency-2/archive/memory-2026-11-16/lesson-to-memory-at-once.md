Write each new lesson to memory the moment it is learned, before the next brief, launch or report: a launch refusal, an assumption that proved wrong, a brief defect, a stamp ahead of the clock. Update an existing memory when one covers it.

**Why:** in the 300k compaction trial (11-14), the same mistakes came back across compactions until written down. Sonnet was named on Opus tickets three times between 15:25 and 18:08, stamps ran ahead of the clock five times, and the W2-88 r8 launch was blocked at 22:00. The owner ended the trial with "trial: full window" and kept this rule anyway (to be recorded with DEC-1183 or the next free id).

**How to apply:** on any miss or refusal, edit or add the memory file in the same response as the fix, then go on. Related: [[brief-worker-model-launcher-picks]], [[check-before-ready-line]].
