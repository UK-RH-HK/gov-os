## Table 2: a design that meets §6.3

The run-time tool is one product package (`src/gov/dispatch`, extended), run by one cron line, with one state file and one log. It also uses one per-session inbox. GPU never spills: embedders and rerankers stay on the GPU; a job that would push GPU memory past its budget waits and never moves to the CPU (5.8; DEC-1158 (3)). Every launch reads its model and effort from `governance/project/criticality.yaml` (the rubric, DEC-1120) and writes them in the launch log. No message passes through the owner.

## Decisions for the owner

1. **The dead-man until slice 1 lands.** §6.1 says it is stopped and its job goes to the tool; A-1 says keep it running until the tool replaces it. Options:
   - (a) Leave it stopped. Cost: nobody wakes a stalled CTO for the days before slice 1.
   - (b) Restart the Haiku sentinel and `deadman.py --watch`. Cost: one small session, and it reverses 6.1.
   - (c) Run the stall check from the dispatcher's cron pass now, with no sentinel. Cost: about 40 lines in the CTO's dispatcher; the wake goes to the CTO's inbox only.

   Recommend (c).
2. **Pushes to your phone from the run-time tool.** RT-6 forbids relays; alerts are not relays. Options:
   - (a) No push: a stall shows in the daily digest. Cost: a night's stall is found in the morning.
   - (b) Push only for a CTO stall (60 min by day, 2 h at night, as today). Cost: a push service in the tick, about 30 lines.
   - (c) Push for a stall and for machine incidents (GPU spill, OOM). Cost: (b) plus more pushes.

   Recommend (b).
3. **Machine-agnostic against "no CPU fallback" (5.8, DEC-1065) on a machine with no GPU (an adopter).** Options:
   - (a) The tool refuses embedding and reranking jobs there and says memory is unavailable. Cost: no memory on GPU-less adopters.
   - (b) Allow the CPU only where no GPU exists; GPU never spills wherever there is one. Cost: it changes DEC-1065, and memory is slower there.
   - (c) Make it a Wave 3 row, driven by friction. Cost: RT-3's verify uses two GPU profiles only.
