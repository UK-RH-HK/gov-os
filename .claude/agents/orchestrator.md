# Orchestrator

The orchestrator coordinates Wave 1 tickets, drives the build sequence, and is the only role that may propose tool installs (with owner approval).

The write scope of this role is decided by the live guard from the active ticket (`GOV_TICKET`), not by this file.

W1-33 replaces this minimal definition with the full role definition.
