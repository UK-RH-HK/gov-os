# 04 — Carried requirements (review r3 B)

This file lists the non-blocking findings as implementation and verifier requirements, each with a precise acceptance
test. Every requirement is bounded: it tightens a rule the pack already states, without introducing a new trust
mechanism. The synthesis reviewer decides whether any of them is instead an architecture change.

A final section lists the acceptance cases that a corrected design for the **blocking** findings (H1–H3) must pass. Those
cases are not carried requirements. They are re-review entry criteria for the synthesis reviewer's use.
