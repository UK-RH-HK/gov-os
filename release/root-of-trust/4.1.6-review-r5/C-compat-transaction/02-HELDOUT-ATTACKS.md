review-r4 B/C/D attack (the nearest prior case is named where one exists). **E** = executed with the real binaries /
real Git; **D** = design reading; **M** = the pack's reference model exercised. Acceptance criterion per attack: does an
ordinary or legacy operation produce a state that is **silently valid** as trust (a `governance/trust` / kernel / lock /

design/binaries resist (fail closed, or the litter is inert and reported); **Gap** = a residual worth a carried
requirement.
