# 04 — Carried requirements (review r4 B)

This file turns the non-blocking findings into requirements that the implementation and the verifier must test.
- **Scope.** Each requirement tightens a rule the pack already states, and each test is independent of builder
  instrumentation.
- **Placement.** The synthesis reviewer decides whether any of them is instead an architecture change.

The last section lists the acceptance cases that a corrected design for the **blocking** findings (H1–H3) must pass.
Those are re-review entry cases, not carried requirements.
