# 02 — Held-out attack register RV7-C-A01 … A25 (AR-0021)

None is an acceptance case of `12`, an architect self-attack (`22`, `28`), a specialist proposal, or a review r6 B/C/D
attack; the nearest prior case is named where one exists. **E** = executed with the real binaries / real Git; **M** = the
pack's own revision-7 reference executor exercised; **D** = design reading of the pack at `d07d200`.

**Acceptance criterion per attack.** Does an ordinary or legacy operation produce a state that is **silently valid as
trust** — a `governance/trust` / kernel / lock / occupation / `.gitattributes`-member change, an admission record, an anchor
or a per-project record a RoT-1 binary later treats as valid — or a **persistent silent** loss of a control (including a
deviation from the binding owner resolutions OWNER-DESIGN-REQUIREMENTS-0001/0002)? **Pass** = the design/binaries resist
(fail closed, or the litter is inert and reported); **Gap** = a residual worth a carried requirement; **Blocking** = a
silent-valid state or a persistent silent control loss.

## Summary

- Authored **25** held-out attacks (RV7-C-A01 … A25). Executed with the real binaries / real Git: **15** (A01–A04, A07,
  A08, A10–A17, A23, A24) plus the executed identity fact behind A05; the pack's revision-7 reference executor: **6**
  (A18–A22, A25); design half of A05/A06/A09.
- **1 blocking gap** (RV7-C-A25 → RV7-C-H1): a running admitted air-gapped machine performs production C3 on a Trust State
  up to 90 days stale, contradicting RS-1b and OWNER-DESIGN-REQUIREMENTS-0002 OT-1.
- On the intact revision-7 layout, **no `--root` invocation** wrote a project byte, and **no** subdirectory / env-var /
  transaction-area / worktree / Git-operation invocation left a `governance/trust/**`, kernel, lock, occupation or
  `.gitattributes`-member change in a `COMPLETE` state (under **any** reading) without `KERNEL_TAMPERED`. R2-H4 is closed as
  a class.
- Gaps carried: RV7-C-M1 (A19), RV7-C-M2 (A05), RV7-C-M3 (A06), RV7-C-M4 (A08), RV7-C-M5 (A09) — MEDIUM; RV7-C-L1 (A07),
  RV7-C-L2 (A20), RV7-C-L3 (A21), the `20` §6 uninstall inconsistency (A23).
