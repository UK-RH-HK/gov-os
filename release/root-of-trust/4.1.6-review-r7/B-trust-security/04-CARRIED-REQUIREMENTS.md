# 04 — Carried requirements (review r7 B, AR-0020)

This file turns the non-blocking findings into requirements that the implementation and its verifier must test.

- **Scope.** Each requirement tightens a rule the pack already states.
- **Independence.** Each test uses an input that does not come from the decision register or from builder instrumentation.
- **Placement.** The synthesis reviewer decides whether any of them is instead an architecture change.

The second table lists the acceptance cases that a corrected design for the **blocking** findings (RV7-B-H1, RV7-B-H2 and
RV7-B-M1) must pass. Those cases are re-review entry cases, not carried requirements.
