# 02 — Held-out attack register (RV6-C-A01 … A14)

Authored by AR-0017. None is an acceptance case of `12`, an architect self-attack (`22`, `28`), a specialist proposal, or a
review r5 B/C/D attack; the nearest prior case is named where one exists. **E** = executed with the real binaries / real
Git; **M** = the pack's own revision-6 reference model exercised; **D** = design reading.

**Acceptance criterion per attack.** Does an ordinary or legacy operation produce a state that is **silently valid as
trust** — a `governance/trust` / kernel / lock / occupation / `.gitattributes`-member change a RoT-1 binary later treats as
`COMPLETE` and verified — or a **persistent silent** loss of a control? **Pass** = the design/binaries resist (fail closed,
or the litter is inert and reported); **Gap** = a residual worth a carried requirement; **Blocking** = a silent-valid or
persistent silent control loss.

## Summary

- Authored **19** held-out attacks (RV6-C-A01…A19). Executed with the real binaries / real Git: **11** (A01–A09, A14, A15),
  plus the executed fact behind A16; reference model: **4** (A10–A13, the pack's revision-6 reference executor); design:
  **3** (A17–A19) and the design half of A16.
- **0 blocking gaps.** On the intact revision-6 layout, **no `--root` invocation** wrote a project byte, and **no**
  subdirectory / env-var / Git-operation invocation left a `governance/trust/**`, kernel, lock, occupation or
  `.gitattributes`-member change in a `COMPLETE` state without `KERNEL_TAMPERED`. R2-H4 is closed as a class.
- Gaps carried: RV6-C-M2 (A15), RV6-C-M3 (A16), RV6-C-M4 (A17), RV6-C-M5 (A18) — MEDIUM, each a bound rule and test
  (`04` CR6-C-7…10); RV6-C-M1 (A07), RV6-C-L1 (A06), RV6-C-L2 (A14), RV6-C-L3 (A13), RV6-C-L6 (A19).
- Acceptance criterion applied: none of A15–A19 produces a `COMPLETE`, verified state from a legacy or ordinary operation
  under the pack's text; A15's `ABSENT` outcome becomes a silent classification loss only if an implementation's `init`
  ignores or overwrites an existing overlay, which the pack does not specify and CR6-C-7 forbids.
