# Output 9 — New Held-Out Architecture Attack Register

These attacks were authored independently of the architect's RT-01…RT-30. The 4.1.6 verifier implements them in its
own harness; builders must not receive harness code. The *expected secure outcome* column is what a corrected RoT-1
(after `11-CORRECTION-DELTA.md`) must produce. The *pack as written* column is this review's reading of the unamended
design.

Every scenario inherits RT rules 1–7 (`12` §1): black-box `gov --json`, a no-trusted-write assertion, a harm assertion
using a restricted record inside the index scope (e.g. `spec/decisions/*.yaml`, as in R2b), typed refusal, and
never-authenticated.
